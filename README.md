**Student:** Shashwat Singh, Varanasi, UP (25.3°N) - NSEP 2026 / OCSC 2027 aspirant
**Start Date:** 17 September 2026 - 4:15 PM IST
**Challenge:** Mobile tower at 10-15m from house terrace. All tutorials say avoid towers. I am testing from dense urban Varanasi.

### Goal
Detect 1420.4 MHz neutral hydrogen line from Milky Way using low-cost wok dish, with custom RFI mitigation for tower at 10-15m distance.

### Hardware Plan
- Reflector: Steel wok (35-40cm dia) from home
- Receiver: RTL-SDR Blog V3 + Nooelec SAWbird+ H1 LNA (1420 MHz filter)
- Extra Filter: Mobile tower (10-15m) notch filter - frequency to be measured on site
- Shielding: Wok back + aluminium mesh to block tower direction
